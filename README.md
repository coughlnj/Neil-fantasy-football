# Neil's Fantasy Football

A home for Neil's fantasy football work: league notes, player data and, later, tools.

## Layout

| Folder   | What goes here                                              |
|----------|-------------------------------------------------------------|
| `data/`  | Player stats, projections, rankings, league exports (CSV etc.). Put large or private files in `data/raw/`, which is not committed. |
| `notes/` | Draft strategy, league rules, trade ideas, weekly notes.    |

## Status

Skeleton only: no language or tooling has been chosen yet. Possible directions:

- Draft rankings and cheat sheets
- League tracking (scores, standings)
- Weekly lineup optimizer
